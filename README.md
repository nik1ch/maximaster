# Каталог картин

## Стек

- Backend: C# / ASP.NET Core
- Frontend: HTML, CSS, JavaScript
- Хранение данных: будет добавлено на следующих этапах

## Текущий этап

Проект находится на этапе инициализации. Сейчас добавлены:

- базовая структура backend и frontend;
- минимальная C# API-заготовка;
- HTML-прототип публичного списка картин;
- HTML-прототип детальной страницы картины;
- отдельная папка открытой админки;
- HTML-прототипы страниц админки для списка, добавления и редактирования;
- общий CSS и JS-заглушки;
- `.gitignore` для C#, IDE, сборочных и временных файлов.


## Как запустить backend

```bash
cd backend/PaintingsCatalog.Api
dotnet run
```

После запуска API будет доступен локально по адресу, который выведет `dotnet run`.
